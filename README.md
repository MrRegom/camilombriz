# Empresas CamiLombriz Ltda. — Experiencia Web 360° VR

Sitio web interactivo de realidad virtual 360° y catálogo agronómico editorial para **Empresas CamiLombriz Ltda.** (Quilpué / Belloto / V Región, Chile).

## 🌿 Características

- **Entornos 360° Reales por Servicio:**
  - `01 Inicio`: Parcela / Terreno V Región (*"Suelo nuevo, vida nueva"*)
  - `02 Sistemas de Riego`: Césped vivo con aspersores pop-up y partículas de rocío hídrico
  - `03 Jardinería & Poda`: Jardín botánico con setos esculpidos y poda en altura
  - `04 Control Fitosanitario SAG`: Huerto de cítricos con técnico en traje de bioseguridad y motopulverizadora
  - `05 Contacto`: Jardín consolidado con llamada a la acción directa a WhatsApp
- **Navegación Intuitiva:**
  - Control de cámara 360° por arrastre táctil o mouse
  - Disolución cinematográfica entre mundos al hacer scroll
  - Catálogo lateral fotográfico editorial con enlace directo a cada escena 360°
  - Conexión directa a WhatsApp oficial (`+56 9 9953 6785`)
- **Rendimiento:**
  - Optimizado para móviles y escritorio con Three.js
  - Texturas 4K comprimidas en WebP de alta fidelidad
  - Paisaje sonoro sintetizado con Web Audio API

## 🚀 Despliegue

Listo para producción en **Vercel**, **Netlify** o cualquier hosting estático.

```bash
# Servidor local de desarrollo
python -m http.server 5500
```
